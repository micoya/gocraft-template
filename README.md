# gocraft-template

基于 [gocraft](https://github.com/micoya/gocraft) 框架的 Go 项目样板工程。

给 `Micoya` 快速创建新项目用的

## Bootstrap

```bash
go install github.com/micoya/gocraft/cmd/gocraft@latest

go craft new <my-project>
```

## AI开发支持

模板内已内置基本的Rules和Skills

仅复制 `_boost` 目录为 `.cursor` , `.trae`, `.claude` 等相应的IDE所需的目录配置
